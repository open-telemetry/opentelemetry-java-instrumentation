# Settings for the Apache RocketMQ remoting-based client instrumentation

| System property                                                      | Type    | Default | Description                                                                                                                                                                                                                                             |
| -------------------------------------------------------------------- | ------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `otel.instrumentation.rocketmq-client.experimental-span-attributes`  | Boolean | `false` | Enable the capture of experimental span attributes.                                                                                                                                                                                                     |
| `otel.instrumentation.rocketmq-client.message-create-spans.enabled`  | Boolean | `true`  | Enable per-message `Create` spans for batch sends when stable messaging semantic conventions are enabled. Overrides the common messaging setting. Disabling this retains `Send` spans and context propagation and does not affect single-message sends. |
| `otel.instrumentation.common.messaging.message-create-spans.enabled` | Boolean | `true`  | Default for batch-send message creation spans when an instrumentation-specific setting is not configured.                                                                                                                                               |
