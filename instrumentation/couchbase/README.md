# Settings for the Couchbase instrumentation

| System property                                               | Type    | Default | Description                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------------------- | ------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `otel.instrumentation.couchbase.emit-experimental-telemetry`  | Boolean | `false` | Enables experimental span attributes for Couchbase 2.x. For Couchbase 3.x, enables the SDK's `request_encoding` and `dispatch_to_server` internal spans, but not experimental span attributes.                                                                                                                                                                     |
| `otel.instrumentation.couchbase.experimental-span-attributes` | Boolean | `false` | For Couchbase 2.x, deprecated alias for `otel.instrumentation.couchbase.emit-experimental-telemetry`. For Couchbase 3.x, enables experimental span attributes and remains a deprecated fallback for enabling SDK detail spans when `otel.instrumentation.couchbase.emit-experimental-telemetry` is unset. |
