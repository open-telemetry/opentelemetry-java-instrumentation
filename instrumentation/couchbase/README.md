# Settings for the Couchbase instrumentation

| System property                                               | Type    | Default | Description                                                                                                                                                                                                                                                |
| ------------------------------------------------------------- | ------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `otel.instrumentation.couchbase.emit-experimental-telemetry`  | Boolean | `false` | Enables the Couchbase SDK's `request_encoding` and `dispatch_to_server` internal spans for 3.x. It does not enable experimental span attributes.                                                                                                           |
| `otel.instrumentation.couchbase.experimental-span-attributes` | Boolean | `false` | Enables experimental span attributes. Until `otel.instrumentation.couchbase.emit-experimental-telemetry` is explicitly set, this deprecated setting also enables the Couchbase SDK's detail spans for backward compatibility. |
