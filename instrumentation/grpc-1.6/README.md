# Settings for the gRPC instrumentation

| System property                                             | Type    | Default | Description                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------------------------------------------------- | ------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `otel.instrumentation.grpc.emit-message-events`             | Boolean | `true`  | Determines whether to emit span event for each individual message received and sent.                                                                                                                                                                                                                                                                                                 |
| `otel.instrumentation.grpc.experimental-span-attributes`    | Boolean | `false` | Enable the capture of experimental span attributes.                                                                                                                                                                                                                                                                                                                                  |
| `otel.instrumentation.grpc.client.request-headers.included` | String  |         | A comma-separated list of ASCII request header key patterns to capture on client spans. Matching is case-insensitive. `?` matches one character and `*` matches zero or more characters. No request headers are captured unless included or excluded patterns are configured. `*` captures all ASCII request headers.                                                                |
| `otel.instrumentation.grpc.client.request-headers.excluded` | String  |         | A comma-separated list of ASCII request header key patterns to exclude from client spans. Matching is case-insensitive. `?` matches one character and `*` matches zero or more characters. Excluded patterns take precedence over included patterns. If only excluded patterns are configured, all other ASCII request headers are captured, which may expose sensitive information. |
| `otel.instrumentation.grpc.server.request-headers.included` | String  |         | A comma-separated list of ASCII request header key patterns to capture on server spans. Matching is case-insensitive. `?` matches one character and `*` matches zero or more characters. No request headers are captured unless included or excluded patterns are configured. `*` captures all ASCII request headers.                                                                |
| `otel.instrumentation.grpc.server.request-headers.excluded` | String  |         | A comma-separated list of ASCII request header key patterns to exclude from server spans. Matching is case-insensitive. `?` matches one character and `*` matches zero or more characters. Excluded patterns take precedence over included patterns. If only excluded patterns are configured, all other ASCII request headers are captured, which may expose sensitive information. |

Captured headers use `rpc.request.header.<key>`, with lowercase keys and string-array values.
Binary metadata and HTTP/2 pseudo-headers are not captured.
